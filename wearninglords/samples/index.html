WearningLords sample files

Vocabulary files for trying the import

WearningLords shares topics and folders as .json files and imports them back. These files are ready to import:

  • Spanish — Food and Drinks — a topic with 14 words, meanings in English.
  • Spanish Starter — a folder with three topics (Food and Drinks, Travel, Everyday Verbs), 35 words.
  • French — Greetings — a topic with 6 words whose meanings are given in nine languages; the app takes the language of its interface and shows it before importing.

On iPhone and iPad

Tap a file above and choose Download. In WearningLords open Settings (the gear on the main screen), tap Import from File… and pick the file from Downloads. A downloaded file can also be opened from the Files app with Share → WearningLords.

On a Mac

Click a file above: it is saved to Downloads. In WearningLords choose File → Import from File… (⌘O), or Settings → Import from File…, and pick the file.

Before adding anything the app shows a preview: the name, the number of words, the first words and where to put it. Importing the same file again offers to make a copy or to add only the new words.

Ready-made sets

When the app runs in a language other than English, Settings → Ready-Made Sets offers 1,950 English words in 13 themes with meanings in that language. To see them on an English device, set the app’s language to, for example, Español: on iPhone and iPad in Settings → WearningLords → Language, on a Mac in System Settings → General → Language & Region → Applications.

Примеры файлов WearningLords

Файлы словаря для проверки импорта

WearningLords делится топиками и папками в файлах .json и загружает их обратно. Эти файлы готовы к импорту:

  • Spanish — Food and Drinks — топик из 14 слов, значения на английском.
  • Spanish Starter — папка из трёх топиков (Food and Drinks, Travel, Everyday Verbs), 35 слов.
  • French — Greetings — топик из 6 слов, значения на девяти языках: приложение берёт язык своего интерфейса и показывает его перед импортом.

На iPhone и iPad

Нажмите на файл выше и выберите «Загрузить». В WearningLords откройте «Настройки» (шестерёнка на главном экране) → «Загрузить из файла…» и выберите файл в «Загрузках». Скачанный файл можно открыть и из приложения «Файлы»: «Поделиться» → WearningLords.

На Mac

Нажмите на файл выше — он сохранится в «Загрузки». В WearningLords выберите «Файл» → «Загрузить из файла…» (⌘O) или «Настройки» → «Загрузить из файла…» и выберите файл.

Перед добавлением приложение показывает превью: название, число слов, первые слова и куда положить. При повторном импорте того же файла оно предложит сделать копию или добавить только новые слова.

Готовые наборы

Когда приложение работает не на английском, в «Настройках» → «Готовые наборы» есть 1950 английских слов в 13 темах со значениями на языке интерфейса.
